# Лабораторная работа №1: Основы интерпретируемости моделей

## Описание
В данной работе исследуются методы интерпретируемого машинного обучения на примере двух задач:

1. **Ловушка «Золотого признака»** — демонстрация проблемы мультиколлинеарности и нелинейных зависимозей в линейных моделях.

2. **Финтех-детектив (The Hidden Pattern)** — поиск скрытых закономерностей в датасете с анкетными данными.

## Используемые технологии
- Python 3.12
- **InterpretML** — библиотека для интерпретируемого ML (EBM — Explainable Boosting Machine)
- **Scikit-learn** — линейная регрессия, метрики
- **Pandas, NumPy** — обработка данных
- **Matplotlib, Seaborn** — визуализация

## Результаты

### Задание 1
- Выявлена проблема мультиколлинеарности между признаками `Experience_Years` и `Coffee_ID`.
- EBM показала **R² = 0.987**, значительно превосходя линейную регрессию (**R² = 0.846**).
- Обнаружена точка перелома на опыте ~1.9 лет, после которой рост зарплаты ускоряется.

### Задание 2
- Построена модель EBM для предсказания дохода по 11 признакам.
- Топ-5 важных признаков:
  1. **User_ID** (12,039) — **красный флаг** (проблема утечки данных!)
  2. **Age** (10,224)
  3. **City** (9,408)
  4. **Education** (7,490)
  5. **Shoe_Size** (1,164)
- Обнаружены подозрительно высокие веса для `User_ID`, что может указывать на переобучение, утечку данных или синтетическое происхождение датасета.
